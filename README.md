## 🏸 BadmintonKu

### Online Badminton Court Booking Platform

<a href="https://github.com/TeguhAldianto/badmintonku">
<img src="https://github-readme-stats.vercel.app/api/pin/?username=TeguhAldianto&repo=badmintonku&theme=tokyonight&hide_border=true" />
</a>

</div>

A modern booking platform focused on digitizing badminton court reservation workflows.

### ⚡ System Concept

```text
Customer
   │
   ├── Browse Courts
   ├── Select Date
   ├── Select Time
   ├── Create Booking
   ├── Payment
   └── Booking History
          │
          ▼
      Backend Logic
          │
          ├── Authentication
          ├── Validation
          ├── Booking Rules
          ├── Payment Flow
          └── Notification
          │
          ▼
        Database
```

### 🛠 Stack

`Next.js 16` `React 19` `TypeScript` `Tailwind CSS 4` `Prisma` `MySQL` `NextAuth`

The repository currently uses Next.js 16, React 19, TypeScript 5, Tailwind CSS 4 and Prisma-related database dependencies.
